## Decisão prática

Um único projeto Vite com `@cloudflare/vite-plugin` empacota React e Hono/Worker. `src/client/`, `src/worker/` e `src/db/` preservam fronteiras modulares sem criar microserviços. Isto substitui a hipótese de monorepo inicial sugerida em [plano](plan.md) — uma simplificação de F0, não alteração dos módulos de produto. O site público Astro permanece independente em `site/` (DEC-044).

## Comandos

```bash
npm ci
npm run db:migrate:local
npm run db:seed:local
npm run verify   # typecheck, lint, unit, runtime, design, build, migrate/seed
npm run dev
```

A aplicação abre em `http://localhost:5173`; `GET /api/health` devolve apenas estado técnico (`phase: f0`, `environment`). Área de prova de componentes: `http://localhost:5173/prova` (issue #16; fora de rotas produtivas). `npm run typecheck`, `npm run lint`, `npm test`, `npm run test:runtime`, `npm run check:design` e `npm run build` executam a validação. `npm run preview` pré-visualiza o Worker compilado.

```bash
npm run cf:typegen
```

Gera tipos quando os bindings evoluírem. Contratos de `DB`, `CLINIC`, `ATTACHMENTS`, `INBOUND_EVENTS` e variáveis por ambiente: [environments.md](environments.md). `wrangler.jsonc` na raiz usa UUID **fictício** só para D1 local; staging/prod têm placeholders recusados por `npm run check:env -- staging|production` até o provisionamento. Não usar `deploy` com IDs fictícios.

## Segurança

Não há login nem rotas de negócio; a interface é deliberadamente um painel de fundação sem dados de clientes. Os dois tenants e as memberships da seed são inteiramente fictícios (`clinic-demo-*`, `user_synth_*`). Rotas `/api/f0/clinic/...` são harness de runtime, não API de produto. Não ligar WhatsApp nem usar dados reais nesta fase.

## Evolução de arquitetura — DEC-038

O checkpoint F0 original precede SQLite operacional por DO/clínica. O D1 continua central para administração e memberships; o `ClinicDurableObject` nesta fase é **apenas harness** (probe SQLite + WebSocket). Adaptar domínio, migrações por instância e testes nas fases seguintes, conforme [ADR-0012](../adr/0012-clinic-durable-object-sqlite.md). A decisão não significa que o domínio operacional já foi implementado nem invalida os checks históricos da F0.
