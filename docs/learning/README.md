# Learning — material-fonte para artigos

Pacote de conhecimento da iniciativa WhatsApp / núcleo conversacional do Tredane.

**Uso:** artigos para Opus Naturalis e LinkedIn, notas de transferência e briefings a outros agentes. **Não** é especificação de produto e **não** substitui [`docs/MVP.md`](../MVP.md), decisões em `docs/product/` nem ADRs.

**Estado geral:** rascunhos e sínteses. Cada ficheiro marca **Confirmado** / **Proposto** / **Em aberto** / **Fora do MVP**. Não inventa métricas nem usa dados reais de clínicas ou clientes.
