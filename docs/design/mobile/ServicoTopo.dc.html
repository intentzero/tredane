Depilação

Ativo
Também chamam de
depilar
Palavras que a cliente pode escrever. A IA percebe o pedido; a resposta usa sempre «Depilação».
Como a cliente escolhe
A cliente junta opções na mesma visita. Preço e tempo somam. Ex.: zonas de depilação.
Para quem
5 zonas são só para feminino, e o serviço está em «Masculino». O serviço não esconde essas opções.
Como se chama cada opção
«Zonas» nos dois dá «1 zonas». Para uma, use «Zona».
